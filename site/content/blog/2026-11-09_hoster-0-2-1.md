0.2.1 makes no change to the binary. It is the release that publishes this version of the docs
site, which only deploys when a release is tagged.

# The docs look like the admin UI

The site now uses the admin UI's design system from [[hoster-0-2-0|0.2.0]]: Catppuccin Latte or
Mocha, following your system setting, JetBrains Mono for code and paths, and the same sidebar,
cards and tables. Each docs page lists the other guides by category in the sidebar, and on wide
screens an "On this page" list sits beside the text.

# A post for every release

The [Releases](/blog/) page has a post for every release since [[hoster-0-1-0|0.1.0]], written for
the people running hoster: what changed, and what to know before updating. The GitHub release keeps
the full list of commits. The [Atom feed](/feed.xml) lets you follow new releases.

# Updating

Not needed; nothing changed in the binary. `hoster update` brings you to 0.2.1 as usual if you
want the version number to match.
