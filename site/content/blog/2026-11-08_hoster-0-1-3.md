This release changes nothing about how hoster runs. The release is the first one to ship this
site.

# The docs have a home

The user guides used to be Markdown files in the repository. They now make up this site, built
with [aphid](https://github.com/LHelge/aphid), with a new [[overview]] page as the entry point. A
broken cross-reference now fails the build, so links between guides stay correct.

The site is deployed by hoster itself. Each release tag packs it into an nginx image and deploys it
through the same OIDC webhook described in [[deploying-from-ci]], following
[[static-sites|the static site guide]] step by step. Messages from the binary, `install.sh`, the
systemd unit and the System page now link here.

# Under the hood

- The release workflow's docs settings no longer leak into the build job's environment, where
  the tests read them as hoster config overrides. That bug stopped the first attempt at this
  release.
- The GitHub Actions now run on their Node 24 versions, and the release build reuses CI's cache.

# Updating

Optional; nothing changed in the binary's behaviour. `hoster update` brings you up to date as usual.
