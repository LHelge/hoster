0.6.1 fixes how the response time chart from [[hoster-0-6-0|0.6.0]] looks on a host with only a
few requests now and then.

# The response time chart on quiet hosts

The chart used to leave a hole wherever a minute (or a longer bucket) had no requests. With
sporadic traffic that is most of the chart, so the p50 and p95 lines fell apart into short
strokes and stray dots, and a p95 dot was hidden whenever it equalled the p50.

A bucket without requests is now drawn at zero. Both lines run the whole range, quiet stretches
lie on the axis and the requests show as peaks. Hovering a bucket still says "no samples" where
there were none, so a zero on the chart is never mistaken for a fast response.

# Updating

```sh
hoster update
```

Or use *Update* on the System page. Nothing changed in `hoster.toml`, in the stack format or in
hoster's database, so rolling back to 0.6.0 is safe and keeps the traffic history.
