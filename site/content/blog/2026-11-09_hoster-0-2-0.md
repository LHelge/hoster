0.2.0 redesigns the admin UI from the ground up. Every page from 0.1 is still there, but each one
was rebuilt against one design system. This site now uses it as well.

# One design system

- **Catppuccin, light and dark.** Latte in light mode and Mocha in dark mode, following your
  system setting. In Latte, the accent and status colours are darkened until all text reaches
  4.5:1 contrast.
- **JetBrains Mono** for everything machine-derived (names, digests, paths, numbers, labels) and
  the system font for prose. The font ships with the binary, so nothing loads from a CDN.
- **Lucide icons**, served as one cached SVG sprite.
- Every page was checked at 1440 px and 375 px in both themes. Primary and destructive actions
  are at least 44 px tall on narrow screens.

# Page by page

- **Shell.** A sidebar with navigation, counts and warning badges. It moves above the page on
  narrow screens.
- **Dashboard.** KPI tiles for traffic and latency, a stacks table and a certificates card.
- **Stacks.** Stacks are shown as cards with a status filter. Each stack has tabs:
  - *Overview*: KPI tiles, slowest routes, routes and volumes.
  - *Services*: uptime and ports. This replaces the old Containers page.
  - *Logs*: per-service chips, *since* presets and a follow switch.
  - *Environment*: env vars and write-only secrets.
  - *Deployments*: history, with a detail page for each deployment.
- **New stack.** The apply page is now an editor. Beside it, the plan and pre-flight checks are
  shown before you confirm.
- **Certificates.** Summary tiles, an alert for failing certificates, a table and bulk actions.
- **Settings.** A section sub-nav, registry credentials as field rows, and read-only views of
  the effective configuration.
- **System.** Version cards, the update flow and facts about the host.

[[overview#the-admin-ui|How hoster works]] describes each page.

# Updating

```sh
hoster update
```

Or use *Update* on the System page. Nothing changed in `hoster.toml` or in the stack file format.
