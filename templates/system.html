Updates

hoster asks GitHub for the latest stable release only when you click the button; it never checks in the background. Updating downloads the release's binary for this architecture, verifies it against the release's SHA256SUMS, snapshots the database and restarts hoster, which drops connections for a few seconds.

Rolling back

Rollback is not offered here. To return to the previous version, log in to the server over SSH as the hoster user and run hoster rollback: it undoes the database migrations the newer version added, switches back and restarts the service. If hoster cannot run at all, follow the manual rollback.
